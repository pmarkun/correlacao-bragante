# Site local · Correlação Bragante

Abra http://127.0.0.1:8765 enquanto o servidor estiver em execução.

Para iniciar novamente, abra um terminal nesta pasta e execute:

```sh
sh iniciar.sh
```

Requisitos: uv e Python disponíveis localmente. O servidor atende apenas neste computador. Para encerrar, pressione Ctrl+C no terminal do servidor.

O arquivo `index.html` também abre diretamente no navegador, sem conexão à internet. Os dados, scripts e documentos originais do pacote foram preservados. O relatório gerado passou a se chamar `index.html`.

Ranking, filtros, mapas e gráficos usam a base incluída no pacote. Não há atualização automática. As informações de origem são as declaradas pelo material recebido; esta adaptação não refez nem auditou os cálculos.
